STUDIO READY

04 / PROCESO / HERRAMIENTAS

El studio
muestra el cómo.

Un laboratorio para entender decisiones: qué herramienta sirve para cada capa y qué parte sigue siendo criterio humano.

PIPELINE VIVO

01

Texto y archivo

Corpus local, narrativa, definiciones, letras y ledger. La estructura editorial llega antes que el efecto.

02

Imagen y vídeo

Fotografía, poster, vídeo hero, color y composición. Cada asset conserva origen y función.

03

Movimiento

GSAP, ScrollTrigger y parallax solo cuando guían la lectura; fallback estático y reduced motion siempre disponibles.

04

3D y campo visual

Three.js para la singularidad del umbral; Blender para renders y loops que puedan vivir fuera del navegador.

05

Verificación

Node, Playwright, teclado, consola y carga directa de rutas. Lo visual se comprueba como producto.

STACK LOCAL

  • FrontendHTML, CSS, JavaScript, GSAP, Three.js.
  • HerramientasVS Code, Roo, Continue, Claude Code y Codex.
  • AssetsFFprobe, Blender, compresión y posters.
  • ControlGit, rama aislada, smoke tests y accesibilidad.

PRINCIPIO

La herramienta no es la obra. Es la forma de hacerla visible.

El studio documenta las decisiones para que el visitante pueda distinguir un prototipo generado, una pieza final y una referencia visual.
