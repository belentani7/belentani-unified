Nodo 02 · La mano humana

EL ARTISTA

El sistema construye; el artista decide. Este nodo es el estudio: el archivo de obras, el CV en cristal, el laberinto creativo y el workflow que convierte intención en interfaz.

◐ EL ARCHIVO

belentani-artist-site-archive: la galería persistente. Cada obra es un commit; cada commit, una declaración.

◈ EL LABERINTO

belentani-laberinto: pieza interactiva donde el visitante se pierde a propósito. No hay salida sin recorrer el error.

✎ EL WORKFLOW

Creative workflow engine: idea → prompt → artefacto → publicación. El proceso, documentado como parte de la obra misma.

MANIFIESTO DEL ESTUDIO

«No diseño páginas: diseño estancias. Quien entra a una obra mía debe sentir el vidrio bajo los dedos y el neón en la retina. La interfaz es el cuerpo del relato; el relato, su lenguaje visual.»

El artista trabaja sobre la base que le dio el núcleo, pero toda obra honesta pasa por el quiebre. La obra más oscura del estudio no se hizo para admirarse: se hizo para sobrevivirse.
