cómo correr una app (desde cero)
1
Abrir PowerShell siempre
10 segundos
  • Tecla Windows → escribe "powershell"
  • Click derecho → "Ejecutar como administrador"
  • Verás una ventana azul/negra con cursor parpadeante
2
Ir a tu carpeta Belentani
5 segundos
  • Escribe el comando de abajo y pulsa Enter
cd C:\Belentani
3
Lanzar el agente OpenCode
5 segundos
  • Escribe el comando abajo
  • Se abre una interfaz en la terminal
  • Ya puedes hablarle en español
opencode
4
Decirle qué construir
tú hablas, él hace
  • Escribe en la terminal lo que quieres
  • Ejemplo: "crea una landing page para mi música JUDAS"
  • Él crea los archivos en C:\Belentani\projects
crea una landing page para mi música. artista: BELENTANI. tema oscuro, cyberpunk, sección con reproductor, bio y contacto. guárdala en projects/landing
5
Abrir el resultado en el navegador
2 segundos
  • Ve a C:\Belentani\projects\landing en el explorador de archivos
  • Doble click en index.html
  • Se abre en Chrome/Edge — eso es tu web funcionando
  • Para subir online gratis → arrastra la carpeta a vercel.com/new

COMANDOS
Copia y pega en PowerShell.
instalar todo (una vez)
npm install -g opencode-ai
npm install -g flowise
pip install demucs f5-tts matchering
uso diario
cd C:\Belentani && opencode
flowise start
crear proyecto nuevo
mkdir C:\Belentani\projects\mi-proyecto && cd C:\Belentani\projects\mi-proyecto && opencode
separar voces con demucs
python -m demucs --two-stems=vocals "C:\ruta\a\tu\cancion.mp3"
lanzar agente openclaw
cd C:\Belentani && openclaw start
script completo de setup (PowerShell admin)
# Pega esto en PowerShell como Administrador Set-ExecutionPolicy Bypass -Scope Process -Force winget install OpenJS.NodeJS.LTS --silent winget install Python.Python.3.11 --silent npm install -g opencode-ai flowise pip install demucs f5-tts New-Item -ItemType Directory -Force -Path "C:\Belentani\projects" New-Item -ItemType Directory -Force -Path "C:\Belentani\audio" Write-Host "LISTO" -ForegroundColor Green
