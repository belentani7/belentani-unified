How Proxies Work in This Studio

When proxy is enabled, all API requests to providers are routed through your configured proxy server. This is useful for: bypassing geo-restrictions (some providers are region-locked), rotating IPs to avoid rate limits, accessing region-specific models, and maintaining privacy. The proxy applies to both task creation and status polling.
